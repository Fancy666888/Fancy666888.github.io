## 项目背景

在浏览高校教师和研究者的个人主页后，我希望建立一个属于自己的长期知识与成果档案。它不只是简历展示页，也承担学习记录、项目复盘和论文归档的功能。

## 当前实现

- 使用 Markdown 维护主要内容，便于版本管理和长期迁移
- 为项目、论文、学习记录和个人经历建立独立栏目
- 支持 BibTeX 论文管理、数学公式、代码高亮和深浅色主题
- 预留 GitHub Pages 静态部署能力

## 当前状态

已经完成个人信息、项目、论文和经历的首轮整理。下一阶段将完善项目过程记录、课程笔记，并在确定部署地址后发布到 GitHub Pages。
